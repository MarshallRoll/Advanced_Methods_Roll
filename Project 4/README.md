This project seeks to understand the operating characteristics of common variable selection techniques in linear regression. The performances of five model selection methods were investigated on a simulated dataset: backward selection using F-tests and p-values, AIC, and BIC as well as LASSO and elastic net regularization. Backward selection begins with a full model and sequentially removing the explanatory variable that contributes the least to model fit until a pre-specified stopping criterion is met. Regularization methods apply a shrinkage penalty directly to the coefficients, so variables with low predictive power are “zeroed out.” The simulated dataset contained some explanatory variables with a true relationship to the outcome and others without a true relationship; the overall goal of model selection algorithms is to correctly select variables with a true signal (sensitivity) and to exclude the variables representing random noise (specificity). Additionally, the final models generated by each selection algorithm over all simulation iterations were evaluated to determine the accuracy with which parameters were estimated (bias) and the uncertainty surrounding these estimates (coverage). Together, these measures elucidate the characteristics of each variable selection algorithm and help to motivate their appropriate use.
